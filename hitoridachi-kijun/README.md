# ひとりだち基準（自社版）

介護職員の技術評価（食事介助・移動介助・入浴介助・服薬介助などを「できない／見守り／ひとりだち」の3段階で評価）を、職員ごとに記録・管理するツールです。社会福祉法人新生福祉会の自社版で、データはブラウザの localStorage にのみ保存され、外部サーバーへは送信されません。

## ファイル

- `hitoridachi-kijun-modern.html` — 本体（単一HTMLファイル、ビルド不要）。ブラウザで直接開くか、簡易HTTPサーバーで配信して使用します。
- `usage-demo.webm` — 使い方ガイドから再生される操作デモ動画（任意）。本体と同じフォルダに置くと自動で読み込まれます。無くてもアプリ自体はエラーにならず、案内文が表示されるだけです。

## 主な機能

- 職員登録・削除、評価区分・項目のカスタム追加・削除（管理者画面）
- 各項目を3段階で評価し、判定日・指導者名・メモを記録
- 職員一覧、CSV書き出し（Excel対応、ファイル名は半角英数字固定）
- バックアップの書き出し・読み込み（JSON、形式チェックあり）
- ダーク／ライトテーマ切替
- GSAP（CDN）を使ったアニメーション。CDNが読み込めない環境でもフォールバックで全機能が動作

## 既知の未対応事項（本格運用前に対応が必要）

- 管理者ログインはクライアント側の簡易チェックのみで、正式な認証・アクセス制御にはなっていません。
- データ（localStorage・バックアップJSONファイルともに）は平文保存です。
- 変更履歴（誰がいつ何を変更したか）を記録する監査ログはありません。

複数の教育担当者で同じデータを共有する運用に進める場合は、Supabase（Auth + Row Level Security）等を使った本格的なログイン・アクセス制御への移行が前提になります。
