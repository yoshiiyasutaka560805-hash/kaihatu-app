# 勤務表 半自動作成（新田楽生苑）

`index.html` をブラウザで開くだけで動く単体アプリ（サーバー不要）。データは端末のブラウザ内（localStorage）にのみ保存。

## 使い方
1. Excelの勤務表を範囲コピー → 「取込」に貼り付け（見出し行 `No／氏名／1 2 3…` が必要）
2. 「必要人数・職員設定」で、表から推定された必要人数・夜勤可否・公休数を確認／修正
3. 休暇系（有休・リ休 等）は自動で固定。希望休などの「公」は Shift+クリックで固定（紫枠）
4. 「自動作成」＝固定以外を作り直す／「空欄だけ埋める」＝入力済みを残す
5. 赤枠（エラー）・橙枠（注意）と右の一覧を見て手で調整 → 「Excel用にコピー」で貼り戻し

## 第1版のルール（取込した表から推定。要確認）
夜→明け（／）→公、連続勤務の上限（既定5日）、公休数（取込時の公の数）、早/日/遅/夜 の1日必要人数（AB/CD別）、遅E・準夜勤（フロア共通）、遅→早の間隔、夜勤回数の偏り。

## 対象外（今後）
日勤系部署（相談員・事務・デイ等）の自動作成、勤怠システム用CSV、祝日自動判定（設定で日にちを入力）。

## テスト
`node tests/run.js <取込用TSVファイル>`（実職員データはリポジトリに置かないこと）
