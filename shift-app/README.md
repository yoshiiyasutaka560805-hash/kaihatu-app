# 勤務表 半自動作成（新田楽生苑）

`index.html` をブラウザで開くだけで動く単体アプリ（サーバー不要）。データは端末のブラウザ内（localStorage）にのみ保存。

## 使い方（毎月の流れ）
1. 初回：Excelの勤務表を範囲コピー → 「① 取込」に貼り付け。2か月目以降は「新しい月を始める」（職員・条件は引き継ぎ、夜勤明けも前月末から引き継ぐ）
2. 「② 希望休入力」：1〜10日に集計した希望休・有休などをクリックで入力（希望休→有休→リ休→誕休→研修）
3. 「③」：必要人数、夜勤可否、祝日、夜勤回数（空欄＝出られる日数に応じて均等）を確認
4. 「④ 非常勤・個別条件」：非常勤・日勤職員の勤務記号、出勤できる曜日、日数、週上限（取込んだ表から自動読取り、個別に修正可）
5. 「シフト作成」：希望休を固定 → 夜勤・準夜勤を均等配分 → 公休配置 → 非常勤を条件どおり配置、まで一括実行
6. 「⑤」で赤枠（エラー）・橙枠（注意）と右の一覧を見て手直し → 「Excel用にコピー」／「閲覧用ファイルを保存」

## 第1版のルール（取込した表から推定。要確認）
夜→明け（／）→公、連続勤務の上限（既定5日）、公休数（取込時の公の数）、早/日/遅/夜 の1日必要人数（AB/CD別）、遅E・準夜勤（フロア共通）、遅→早の間隔、夜勤回数の偏り。

## 対象外（今後）
日勤系部署（相談員・事務・デイ等）の自動作成、勤怠システム用CSV、祝日自動判定（設定で日にちを入力）。

## テスト
`node tests/run.js <取込用TSVファイル>`／`node tests/run2.js <TSV>`（希望休・非常勤・新月）（実職員データはリポジトリに置かないこと）

## 社内運用（A案）
- `index.html`（編集用）は編集者10名程度のみがアクセスできるフォルダに置く。データは各編集者のPCのブラウザ内に保存される。
- 確定したら「閲覧用ファイルを保存」で作った `勤務表_YYYY-MM_閲覧用.html` を、全職員が読める共有フォルダに置く（編集機能なし・外部通信なし）。
- 両ファイルとも CSP により外部への通信は禁止されている。
