勤務表アプリ（社内サーバー版）配布ファイル
=========================================
中身：shift-app フォルダ（アプリ本体 index.html と、サーバー server フォルダ）

【情シスの方へ：導入の流れ】
1. このZIPを、社内サーバーの作業フォルダ（例 C:\kaihatu-app）に展開する。
   → C:\kaihatu-app\shift-app\index.html と C:\kaihatu-app\shift-app\server\... になるように。
2. Node.js 22 LTS をインストールする（導入時のみインターネットが必要。以後、アプリは外部と通信しません）。
3. 試験起動：shift-app\server\start-test.bat をダブルクリック → サーバー上のブラウザで http://localhost:8443/ を開き、
   表示される初期パスワードでログイン → パスワード変更 → 画面右上付近の「架空データで試す」で動作確認。
   （試験データは shift-app\test-data に保存されます。確認後に削除してください）
4. 本番設置：shift-app\server\WINDOWS-QUICKSTART.md の手順（専用アカウント、HTTPS、ファイアウォール、
   サービス化、バックアップ、ユーザー登録）に従う。詳細・運用は OPERATIONS.md。
5. 公開範囲：社内ネットワークのみ。インターネットへは公開しないでください。

【注意】
- このZIPに実データ（職員名・勤務表）は含まれていません。
- Windows用のスクリプト（PowerShell・bat）は、開発環境では実機検証できていません。必ずテスト用サーバーで確認してから本番へ。
- 職員名・勤務・休暇は個人情報です。サーバーのデータフォルダのアクセス権・バックアップ・ログの保管期間は、法人の個人情報保護方針に従って決めてください。
