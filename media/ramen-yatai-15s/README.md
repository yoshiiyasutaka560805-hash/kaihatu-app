# 屋台ラーメン 15秒リール

`ramen_yatai_15s.mp4` — SNS向けの縦型ショート動画。

| 項目 | 内容 |
|---|---|
| 解像度 | 1080 × 1920 (9:16 縦型) |
| 長さ | 15.000 秒 / 30fps |
| 映像 | H.264 (High, CRF 19) |
| 音声 | AAC 192kbps 48kHz ステレオ |
| サイズ | 約 10.9 MB |

## 構成（切り替わりは 96BPM の拍に合わせています）

| # | 時間 | 素材 | テロップ |
|---|---|---|---|
| 1 | 0.00 – 3.00 | 動画: 赤提灯 | 今夜は屋台のラーメン / RAMEN YATAI |
| 2 | 2.60 – 5.20 | 写真: 屋台の引き画 | 赤提灯に誘われて |
| 3 | 4.80 – 8.30 | 動画: 調理中の厨房 | 一杯ずつ、丁寧に |
| 4 | 7.90 – 12.07 | 写真: 醤油ラーメン | 澄んだ醤油スープ |
| 5 | 11.67 – 15.00 | 写真: 集合セルフィー | ごちそうさまでした / THANK YOU |

各カットは 0.4 秒のクロスフェードで繋いでいます。冒頭は黒からのフェードイン、
ラストはフェードアウトで終わります。

## 演出のポイント

- **HDRトーンマップ** — 元動画は HLG (HDR) 収録のため、そのまま使うと提灯の赤が
  くすんで橙色に見える。`zscale` + `tonemap=hable` で BT.709 に変換して発色を戻している。
- **横写真を縦画面へ** — 4:3 の写真は 9:16 に切り抜くと器が切れてしまうので、
  背景に同じ写真をぼかして敷き、前面に全体を配置（リール定番のレイアウト）。
- **ケンバーンズ** — 写真は静止画なので、ゆっくりズームで動きを付けている
  （ラーメンは 13% 寄り、セルフィーは軽く引き）。
- **テロップ** — ffmpeg の静的ビルドに `drawtext` が無いため、Pillow で
  IPAゴシックの字送り付き PNG を生成して `overlay` で合成している（`make_titles.py`）。

## 音楽について

著作権のある楽曲は使えないため、**BGMはこのリポジトリ内のスクリプトで合成した
オリジナル**です（`make_music.py`）。ロイヤリティフリーでそのまま公開できます。

- 96BPM / 4拍子 / 6小節 = ちょうど 15.000 秒
- コード進行: Fmaj7 → Em7 → Dm7 → G7 → Cmaj7 → Cmaj9（最後の小節でセルフィーに解決）
- 音色はすべて sine 合成: エレピ風のコード、ベース、キック / スネア / ハイハット、
  ベル系のメロディ（Cメジャー・ペンタトニック）、lo-fi 感のノイズ、簡易リバーブ
- 屋台の環境音（元動画の音声）を BGM の下に小さく重ねて臨場感を足している
