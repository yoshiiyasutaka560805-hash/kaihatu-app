# リアネット 求職者向け 集客素材

有料職業紹介事業「リアネット」が、介護職を探している求職者に向けて出すInstagram投稿の素材。
介護施設の採用キット（`../kouhou-asset-kit/`）とは別ブランドとして、緑基調の配色にしている。

| 色 | 用途 |
|---|---|
| `#0F3D34` 深い緑 | 地色（タイトル・エンドカード） |
| `#1F7A5C` 緑 | STEPバッジ、ブランド色 |
| `#7FD1B9` ミント | 差し色・罫線 |
| `#FF7A59` コーラル | 行動喚起（CTAボタン） |
| `#F2F7F4` 明るい地 | 本文カットの背景 |

写真が無くても成立するテキスト主体の構成。素材が用意できたら、背景ループを
写真・動画に差し替えられる。

```bash
./build.sh assets   # BGM・背景ループ・テロップを作り直す
./build.sh reel     # リールを組む
```

文言は `make_reel_overlays.py` の `TEXTS` を書き換える。

## 法令まわりで確認が必要なこと

有料職業紹介の広告になるため、投稿前に次の3点を確認すること。

1. **厚生労働大臣許可番号を実際の番号に置き換える。**
   現在は `◯◯-ユ-◯◯◯◯◯◯` のプレースホルダ。エンドカードに表示枠を用意してある。
2. **「ご相談・ご紹介は無料です」が自社の運用と合っているか。**
   職業安定法では求職者からの手数料徴収は原則禁止だが、文言は実態に合わせること。
3. **職業安定法の的確表示義務。**
   賃金・勤務地・雇用形態について、誤解を与える表示をしない。
   「高収入」「即日勤務可」などの断定は根拠のある範囲に留める。
