# 広報・採用リール 素材キット

社会福祉法人新生福祉会の Instagram リール（1080×1920 / 9:16）用の素材一式。
色は既存アプリのパレット（`#101A2E` / `#2F6FED` / `#FFC857` / `#EEF3FB`）に合わせてある。

**素材はすべてこのリポジトリ内のスクリプトで生成したオリジナル**なので、
外部の権利関係が一切発生しない。そのまま商用利用できる。

## 中身

| ファイル | 内容 |
|---|---|
| `bgm_akarui.wav / .mp3` | 明るい・前向き 100BPM — 採用・募集向け |
| `bgm_odayaka.wav / .mp3` | おだやか・信頼 84BPM — 施設紹介・日常の様子 |
| `bgm_maeuki.wav / .mp3` | 背中を押す 108BPM — 締め・行動喚起 |
| `se_whoosh / se_pop / se_chime / se_tap` | 効果音4種（転換・テロップ登場・強調・タップ） |
| `bg_gradient.mp4` | 濃紺グラデーション 6秒ループ。白文字向け |
| `bg_bokeh.mp4` | 暖色の玉ボケ 6秒ループ。カードの下地 |
| `bg_paper.mp4` | 明るい紙地に光の帯 6秒ループ。濃い文字向け |
| `card_title.mp4` | タイトルカード 3.0秒 |
| `card_end.mp4` | エンドカード 3.5秒（募集条件＋CTA） |
| `demo_reel.mp4` | 構成が分かる15秒のデモ |
| `ai-prompts.md` | 外部AIツール用のプロンプト集 |

BGMは全曲15.000秒ちょうど、−14 LUFS（SNS標準）。背景ループは動きの周期を尺と
一致させてあるので、何回繋いでも継ぎ目が出ない。

> **⚠️ カードの文言は仮です。** `make_cards.py` の `TEXTS` に入っている
> 「介護の仕事を、いちから覚える。」「未経験から始められます」「資格取得を支援します」
> 「見学だけでも歓迎です」は、こちらで置いた**プレースホルダ**です。
> 実際の待遇・制度に合わせて必ず差し替えてください。事実と違う条件を採用広告に
> 載せることになります。

## 使い方

```bash
# 1. カードの文言を変える
python3 make_cards.py \
  --title "未経験から、" --title2 "はじめる介護。" \
  --end-head "見学だけでも歓迎です" \
  --end-lines "週2日から相談できます" "資格取得を支援します" "送迎あり" \
  --end-cta "詳しくはプロフィールから"
./build.sh cards

# 2. 素材3点でリールを組む（写真でも動画でもよい／横位置でも可）
SLOT1=photo1.jpg SLOT2=movie.mp4 SLOT3=photo2.jpg \
CAP1="日々の様子" CAP2="先輩と一緒に" CAP3="研修も充実" \
BGM=bgm_akarui.wav ./build.sh reel     # → reel.mp4（15.000秒）

# 素材を作り直す場合
./build.sh assets
```

構成は「タイトルカード 3.0秒 → 素材3カット 各3.4秒 → エンドカード 3.5秒」で、
0.4秒のクロスフェードを挟んで合計15.000秒。カットの切り替えはBGMの拍に合う位置にある。

## テロップの位置について

リールは画面の上下左右をアプリのUIが覆う。この安全域の外に文字を置くと隠れる。

| 領域 | サイズ |
|---|---|
| 上 | 250px |
| 下（投稿文・ユーザー名・音源） | 420px＝y1500以降 |
| 下部右（いいね等のボタン） | 180px |
| 左右 | 各60px |

`make_captions.py` の `CAPTION_Y`（=1285）と `make_cards.py` の配置は、
すべてこの内側に収まるようにしてある。文言を長くするときも y1400 を超えないこと。

## 必要なもの

- ffmpeg（`zscale` / `zoompan` / `xfade` / `loudnorm` 対応ビルド）
- Python 3 + numpy + Pillow
- IPAゴシック（`/usr/share/fonts/truetype/fonts-japanese-gothic.ttf`）

Windowsで動かす場合は ffmpeg のパスを `FF` で渡す:
`FF=C:\ffmpeg\bin\ffmpeg.exe ./build.sh reel`
