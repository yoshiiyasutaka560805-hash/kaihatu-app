## 投稿前に確認すること

1. **「ご相談・ご紹介は無料です」が自社の運用と合っているか。**
   職業安定法では求職者からの手数料徴収は原則禁止だが、文言は実態に合わせること。
2. **職業安定法の的確表示義務。**
   賃金・勤務地・雇用形態について、誤解を与える表示をしない。
   「高収入」「即日勤務可」などの断定は根拠のある範囲に留める。
3. **対応エリア・職種の範囲。**
   現在の素材は介護職を前提にした文言。他職種にも広げる場合は文言を調整すること。
