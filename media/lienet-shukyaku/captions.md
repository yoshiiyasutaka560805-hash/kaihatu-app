# 投稿文（キャプション）

3つの素材それぞれの本文。**コピーしてそのまま貼れる形**にしてある。

## 書き方の前提

- **1行目が検索対象。** 求職者が実際に打つ言葉（東京／介護／転職／夜勤／辞めたい）を1行目に入れる。
  ハッシュタグが5個に減った分、拾われる入口はここに移っている
- **表示されるのは冒頭2行だけ。** 残りは「…続きを読む」に隠れる。
  1〜2行目で「自分の話だ」と思わせないと本文は読まれない
- **上限2200文字。** 以下はいずれも600文字前後で、余裕がある
- **CTAは1つだけ。** 「プロフィールのリンク」以外の行き先を混ぜない

### `hashtags.md` から1点変えている

`hashtags.md` ではカルーセルに `#介護士あるある #介護士の日常` を、地名タグなしで割り当てていた。

### 名言を2つに絞った理由

**読む時間です。** 15秒に入るのは4カットで、1枚あたり4.4秒。
日本語を落ち着いて読める速さは毎秒8字程度なので、1枚に入るのは30字強が限界。
3つ入れると1枚3.4秒になり、リンカーンの34字も松下幸之助の43字も読み切れません。

### 13のうちこの2つを選んだ理由

いただいた名言のうち、**「壁を越えろ」「諦めずに叩き続けろ」系は外しました。**

| 外した名言 | 理由 |
|---|---|
| イチロー「壁は越えられる可能性がある人にしかやってこない」 | 今の職場で耐えろ、と読める |
| 松岡修造「90回まで来ていても諦めてしまう」 | 同じ。介護現場に「もっと頑張れ」は逆効果 |
| 徳川家康「怒りを敵と思へ」 | 我慢を求める側の言葉になる |
| ジョン・F・ケネディ「敵を許すことだ」 | トーンが強く、職場の話に重い |

**人材紹介が「諦めるな、耐えろ」と言うと、自社の提案と矛盾します。**
当社が売っているのは「職場は選び直せる」ことなので、
「耐えろ」と言った直後に「転職しませんか」と続けると筋が通りません。

選んだ2つはどちらも**「立ち上がる」「やり直す」**の言葉で、
エンドカードの「立ち上がる場所は、変えてもいい」に自然につながります。
名言が投稿の主張と同じ方向を向いている状態です。

### 残りの11個はカルーセル向き

カルーセルは20枚まで入り、**読む時間の制限がありません。**
「落ち込んだ時に効く言葉」「人間関係で悩んだ時の言葉」の2本に分けると、
いただいた13個をほぼ使い切れます。必要なら作ります。

### リールで外した4つをカルーセルには入れた理由

リールでは「壁を越えろ」「諦めるな」系（イチロー・松岡修造・徳川家康・ケネディ）を外した。
**カルーセルでは入れている。矛盾していないのは、置き方が違うから。**

リールは1つの主張を通す形なので、「耐えろ」の直後に「転職しませんか」を置くと筋が通らない。
カルーセルは**言葉を並べて読み手が選ぶ形**で、7つのうち1つが「壁を叩く」話でも投稿全体の主張にはならない。

そのうえで、各ページに**添え書きを1行入れて向きを揃えている。**

| 言葉 | 添え書き |
|---|---|
| イチロー「壁はチャンス」 | 同じ壁を叩き続けなくてもいい。越える場所は選べます |
| 松岡修造「90回で諦める」 | あと10回か、それとも別の壁か。見極めは一人でしなくていい |
| 徳川家康「怒りを敵と思へ」 | その場で言い返さずに済むと、選べる道が残ります |
| ケネディ「敵を許すことだ」 | 許すのは自分のため。忘れないのは、次に同じ場所を選ばないため |

**添え書きなしで「壁はチャンス」だけを出すと、我慢を勧める投稿になります。**
最終ページの「立ち上がる場所は、変えてもいい」「人は変えられなくても、職場は選べます」まで
含めて1つの主張になるよう組んでいる。

### ページ数を削るなら

⑥は9ページある。反応を見て短くするなら、**徳川家康とケネディの2枚を抜いて7ページ**にするのが先。
この2つは添え書きで向きを変えているぶん、他より説明が要る。

## 投稿前に確定させること

1. **地名タグの表記** — `#東京介護求人` / `#介護求人東京` / `#東京介護転職` の件数をアプリで見比べ、
   最多の1つに統一する。上の3つとも同じ語に置換すること
2. **「ご相談・ご紹介は無料です／求職者の方から手数料はいただきません」** が実際の運用と合っているか。
   3投稿すべてに入っている

## 投稿の順番

| 順 | 投稿 | 理由 |
|---|---|---|
| 0 | プロフィール整備 | **3投稿すべてが「プロフィールのリンクから」で終わる。** 未設定だと導線が切れる |
| 1 | ① サービス紹介リール | アカウントの説明になる |
| 2 | ③ カルーセル | 保存されやすい |
| 3 | ② 人手不足リール | 最もリーチを取る。**先に2本置いてから出す** |

②を最後に回すのは、これで届いた新規がプロフィールを見たときに空にしないため。
逆順にすると、いちばん届いた回の訪問者を取りこぼす。
