# ハッシュタグ設計

## 前提: 2025年12月18日から、1投稿あたり5個まで

Instagram の Adam Mosseri 氏が @Creators で発表。上限が30個から5個に変わった。
フィード投稿とリールが対象で、6個以上入れるとエラーになるか、リンクにならず黒い文字のまま残る。
ストーリーズとライブは現時点で対象外。

「関連するタグを30個並べる」旧来のやり方は、いま実行するとそもそも投稿できない。

## 投稿別の5個セット

### リール（サービス紹介）

```
#介護転職 #介護求人 #介護士の転職 #介護のお仕事 #Lienet
```

### バナー（無料相談の告知）

```
#介護転職相談 #介護求人 #介護職員募集 #転職相談 #Lienet
```

### カルーセル（お悩み→解決）

```
#介護の悩み #介護転職 #介護士あるある #介護職の転職 #Lienet
```

1投稿につき1セット。混ぜない。毎回まったく同じ組み合わせは避け、投稿内容に合わせて3セットを回す。

## 5個の配分

| 階層 | 投稿件数の目安 | 5個のうち | 役割 |
|---|---|---|---|
| ビッグ | 50,000件〜 | 0〜1個 | 母数は大きいが数分で流れる。入れても1個まで |
| ミドル | 10,000〜50,000件 | 2個 | 主戦場。上位表示を狙えて母数もある |
| スモール | 200〜1,000件 | 1〜2個 | 上位に残りやすい。意図が絞れている＝相談につながる |
| ブランド | — | 1個 | `#Lienet`。過去投稿をまとめて見せる導線 |

## ⚠️ この5個は「案」

Instagramはこの開発環境から接続できず（ネットワークポリシーでブロック）、
**実際の投稿件数を測って選んだものではない。** 投稿件数は公開データにも出ていない。
下の手順で確認してから確定すること。1タグ30秒で終わる。

### 投稿件数の確認手順

1. Instagramアプリの検索タブでタグ名を入力する
2. 候補に「◯◯件の投稿」と出るので、その数を控える
3. 10,000〜50,000件ならミドル、200〜1,000件ならスモールとして採用。50,000件超はビッグ枠の1個だけ
4. 件数が桁違いだったタグは近い言い回しに差し替える
   （例: `#介護転職` が大きすぎる → `#介護転職活動` `#介護転職相談`）
5. 上位に並んでいる投稿が自社と同じ層に向いているかも見る。
   求人ではなく施設の日常ばかりなら、そのタグはずれている

## 5個時代に効くのは、むしろ投稿文

タグ枠が6分の1になったぶん、検索の受け皿がキャプションとプロフィールに移っている。

- **1行目に検索されたい言葉を置く。**
  「介護のお仕事、一人で探さない」より「介護の転職相談、無料で承ります｜東京」のほうが拾われる
- **プロフィールの「名前」欄にキーワードを入れる。** ここは検索対象。
  `Lienet｜介護の転職相談` のようにすると、社名を知らない人にも当たる
- **地名を1つ決めて入れる。** 本社が港区北青山なので `#東京介護求人` など。
  対応エリアが決まっているなら市区名まで入れる。地名は競合が一気に減る

## 未確定

**対応エリア。** 「東京都内」なのか「港区・渋谷区中心」なのかで、入れるべき地名タグが変わる。
エリアが絞れているほど、少ない件数のタグで上位を取れる。
