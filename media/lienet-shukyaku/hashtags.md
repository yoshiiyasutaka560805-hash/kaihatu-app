# ハッシュタグ設計

**対象: 東京の転職先を探している介護職の求職者。**
求職者が自分から打つ言葉を軸に組んでいる。

## 前提: 2025年12月18日から、1投稿あたり5個まで

Adam Mosseri 氏が @Creators で発表。上限が30個から5個に変わった。
フィード投稿とリールが対象で、6個以上入れるとエラーになるか、リンクにならず黒い文字のまま残る。
ストーリーズとライブは現時点で対象外（1〜3個が目安）。

枠が6分の1になったので、**1枠でも「誰も検索しない語」に使うと痛い。**

## 求職者は「募集」では探していない

同じ話題でも、施設が出す言葉と求職者が打つ言葉は違う。

### 使わない（採用側の語）

| タグ | 理由 |
|---|---|
| `#介護職員募集` | 「募集」は施設が出す告知の言葉。仕事を探している人は「募集」では検索しない |
| `#介護求人` | 求人サイトと事業者の投稿で埋まっていて、求職者どうしの回遊が起きにくい |
| `#介護転職相談` | 「相談」は提供側の言い方。本人は「転職したい」「辞めたい」と打つ |
| `#転職相談` | 同じ理由。かつ介護以外が大量に混ざる |

### 使う（求職者本人の語）

| タグ | 性質 |
|---|---|
| `#介護士の転職` `#介護転職` | 当事者が自分の状況として打つ言葉 |
| `#転職したい` `#介護辞めたい` | いま気持ちが動いている人の言葉。意図が最も強い |
| `#夜勤明け` `#介護士あるある` `#介護士の日常` | 求職中でなくても毎日見ている。ここで知られて、動くときに思い出される |
| `#介護士の給料` `#介護福祉士` `#実務者研修` | 条件と資格。転職を考える理由そのもの |

### ただし、関連性は外さない

5個制限は「無関係なタグで検索を荒らすのを止める」ための変更。
**件数が多いからといって投稿内容と関係ないタグを付けると逆に評価が落ちる。**
`#夜勤明け` はサービス紹介の投稿に付けるものではなく、**夜勤の話をする投稿を作ってから**使う。

## いまある3投稿の5個セット

### リール（サービス紹介）

```
#介護転職 #介護士の転職 #転職したい #東京介護求人 #Lienet
```

### バナー（無料相談の告知）

```
#介護辞めたい #介護転職 #転職したい #東京介護求人 #Lienet
```

`#介護辞めたい` はトーンが強いと感じる場合、`#介護士の転職` に差し替える。
意図の強さは落ちるが印象は穏やかになる。

### カルーセル（お悩み→解決）

```
#介護の悩み #介護士あるある #介護士の日常 #介護転職 #Lienet
```

この投稿だけ地名を外している。悩みへの共感は東京に限らず広く届いたほうがよく、
プロフィールに来てから東京と分かれば十分。

## 5個の配分

| 階層 | 投稿件数の目安 | 5個のうち | 役割 |
|---|---|---|---|
| ビッグ | 50,000件〜 | 0〜1個 | 母数は大きいが数分で流れる |
| ミドル | 10,000〜50,000件 | 2〜3個 | 主戦場。上位表示を狙えて母数もある |
| スモール | 200〜1,000件 | 1〜2個 | 上位に残りやすい。意図が絞れている |
| 地名 | — | 0〜1個 | `#東京介護求人`。エリア外の流入を切る |
| ブランド | — | 1個 | `#Lienet`。過去投稿をまとめて見せる導線 |

## 求職者が集まる投稿テーマ

求職者の多い巨大タグは、内容が合う投稿を作らないと使えない。
逆に言えば、この5テーマを作ればそのタグが正当に使える。**ここが一番効く。**

| テーマ | 投稿の例 | 付けられるタグ |
|---|---|---|
| 給料 | 東京の介護職の給与レンジ、資格手当・夜勤手当の相場 | `#介護士の給料 #介護転職 #東京介護求人 #転職したい #Lienet` |
| 夜勤 | 夜勤ありなしで手取りがどう変わるか、日勤のみの求人は実際あるのか | `#夜勤明け #介護士の日常 #介護転職 #東京介護求人 #Lienet` |
| 資格 | 実務者研修・介護福祉士で条件がどれだけ変わるか、支援制度のある職場 | `#介護福祉士 #実務者研修 #介護転職 #東京介護求人 #Lienet` |
| 未経験 | 未経験で入った人が最初の3か月で何をするか | `#未経験から介護 #介護転職 #転職したい #東京介護求人 #Lienet` |
| 職場の人間関係 | 面接で職場の雰囲気を見抜く質問、施設形態ごとの働き方の違い | `#介護の悩み #介護士あるある #介護転職 #転職したい #Lienet` |

給料と夜勤は転職を考える理由そのものなので反応が読みやすい。
資格と未経験は自社が答えを持っている領域で、専門性が伝わる。
サービス紹介の投稿だけを続けても、求職者のタイムラインには入っていけない。

## ⚠️ 件数は未計測

ここに挙げたタグは**件数を測って選んだものではない。**
Instagramはこの開発環境から接続できず（ネットワークポリシーでブロック）、
投稿件数は公開データにも出ていない。ログインしたアプリでしか見えない数字。

### 確認手順（1タグ30秒）

1. アプリの検索タブでタグ名を入力する
2. 候補に「◯◯件の投稿」と出るので控える
3. 10,000〜50,000件ならミドル、200〜1,000件ならスモールとして採用。50,000件超はビッグ枠1個だけ
4. 件数が桁違いなら近い言い回しに差し替える
   （例: `#転職したい` が大きすぎる → `#介護士の転職` `#介護転職活動`）
5. **上位に並ぶ投稿が求職者向けかを見る。**
   求人サイトの広告ばかりなら、そのタグは事業者の場になっているので外す

### 地名タグは表記を1つに決める

`#東京介護求人` `#介護求人東京` `#東京介護転職` は別のタグとして扱われる。
**件数の最も多い1つに統一**し、以後ずっとそれだけを使う。分散させると投稿が貯まらない。

区名（`#港区介護求人` など）は入れない。求職者が探しているのは「東京の求人」で、自社の所在地ではない。

## 5個時代に効くのは、むしろ投稿文

- **1行目に、求職者が打つ言葉をそのまま置く。**
  「介護のお仕事、一人で探さない」より
  `東京の介護、夜勤なしで手取りいくら？｜無料相談` のほうが拾われる
- **プロフィールの「名前」欄にキーワードを入れる。** ここは検索対象。
  `Lienet｜東京の介護転職`
- **同じ5個を毎回使い回さない。** 投稿内容に合わせてセットを回す
