# ショートステイAI秘書（施設LAN内専用）

生活相談員の「送迎手順」「書類期限」の対応漏れを、人の努力ではなく**アプリ側から先に知らせる**ことで防ぐ。

## 起動
```
npm install
set FACILITY_ADDRESS=施設の住所          (必須: ルート計算の起点/終点)
set GOOGLE_MAPS_API_KEY=...             (任意: 未設定なら所要時間は未計算、Googleマップのリンクのみ)
npm start                               → http://localhost:3100
```
初回アクセスで管理者アカウントを登録（パスワード10文字以上）。

## 個人情報の扱い
- 氏名・電話・住所・緊急連絡先・メモは **AES-256-GCM で列暗号化**、書類スキャンも暗号化保存。鍵は `data/.key`（または `APP_DATA_KEY`）。**DBと別の媒体にも保管**（紛失すると復号不能）
- 外部（Google Routes API）へ送るのは**住所のみ**。氏名・電話は送らない。画面/共有用の氏名は「姓イニシャル＋名」
- LAN(10/172.16/192.168)・Tailscale(100.64/10)・ループバック以外のIPは接続拒否。**ルーターのポート開放は禁止**
- スマホは施設Wi-Fi、または Tailscale 等のVPN経由で `http://<PCのTailscale IP>:3100` を開く
- ログイン: bcrypt、5回失敗で15分ロック、無操作30分で失効（画面は15分で自動ログアウト）、操作ログ、紛失時は管理画面から端末/全端末を即時無効化
- Windows は BitLocker 等のディスク暗号化を有効にすること

## 注意
- ルート案・同乗可否は**候補提示**。最終判断と介護保険上の記録は担当者が行う
- Googleへ住所を送ること自体が個人情報の第三者提供/委託に当たり得る。法人の個人情報保護方針・Google規約を確認のうえ `GOOGLE_MAPS_API_KEY` を設定すること
- HTTPS化（Tailscale証明書等）を推奨。`node:sqlite` を使用（Node 22.13+）
