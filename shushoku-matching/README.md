# 求職者マッチング（株式会社リアネット 職業紹介業務用）

求職者の希望条件を登録し、ハローワーク求人DBと照合してマッチング判定（ルールスコア＋Claudeによる適合理由の補足）を行う社内ツール。
**判定は補助情報であり、紹介の可否は担当者が最終判断する。**

## 構成
| 区分 | 内容 |
|---|---|
| backend | Express + better-sqlite3 + node-cron（`http://127.0.0.1:3101`） |
| frontend | React + Vite（`http://127.0.0.1:5180`） |
| DB | `data/matching.db`（Git管理外。新生福祉会の `data/kaihatu.db` とは完全分離） |
| 公開 | しない（個人情報を扱うためローカル運用。ルートの `.vercelignore` で除外済み） |

## 起動
```
cd backend  && npm install && npm run seed   # seed は架空のサンプルデータ（任意）
cd frontend && npm install
.\start.ps1
```
AI補足を使う場合は `ANTHROPIC_API_KEY` を設定（未設定ならルール判定のみで動作）。モデルは `CLAUDE_MODEL` で変更可（既定 `claude-opus-5-5`）。

## マッチング判定
1. **足切り**：紹介期限切れ／通勤可能範囲外／必須資格不足／賃金上限が希望未満／夜勤不可×交替制／勤務可能時間外／週勤務日数超過／年齢制限（例外事由の記載がある求人のみ）
2. **加点（100点）**：職種30・賃金25・勤務地15・雇用形態10・休日10・経験資格10
3. **注意表示**（除外しない）：例外事由のない年齢条件、外国籍×外国人雇用不可/不明、賃金形態の換算
4. **AI補足**：上位N件のみ。氏名・カナ・電話・メール・住所・生年月日は送信せず、年代・市区町村・条件のみ送信。求職者ごとの同意が必要。

資格は「保有資格名が要件名を含む」場合に一致し、介護福祉士 ⊇ 実務者研修 ⊇ 初任者研修 の上位資格を考慮。

## 求人の取込
| 方法 | 状態 | 備考 |
|---|---|---|
| CSV手動取込 | 稼働 | 求人DB画面から。テンプレートあり。UTF-8/Shift_JIS対応、求人番号で上書き |
| 求人・求職情報提供サービス | 承認後に有効化 | 労働局への利用申請が必要。受領CSVを設定フォルダに置くと夜間に取込。項目名が異なる場合は `backend/services/postingStore.js` の `FIELD_ALIASES` に追加 |
| 自動巡回 | **既定無効** | 利用規約の確認が前提。`crawler_enabled` と `crawler_terms_confirmed` の両方がONの時のみ稼働。robots.txt遵守、3秒以上の間隔、1回200ページ上限。画面解析部（parser）は確認後に実装 |

## 法令・運用上の注意
- 求職者の個人情報は職業安定法5条の5・個人情報適正管理規程に従う。登録時に同意日を必須入力。操作は `audit_log` に記録。
- 年齢・性別・国籍による不当な選別をしない（年齢制限は例外事由がある求人のみ判定に使用）。
- 外国籍求職者は在留資格上の就労可否を必ず確認。
- 求人情報の二次利用範囲は提供元の条件に従う。
