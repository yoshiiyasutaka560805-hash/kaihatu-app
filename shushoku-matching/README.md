# 求職者マッチング（株式会社リアネット 職業紹介業務用）

有料職業紹介の業務を、求職受付から紹介・成約・請求・定着フォロー・法定帳簿・事業報告まで一貫して管理する社内ツール。
ハローワーク求人と自社で受け付けた求人を求職者の条件と照合し、ルール判定とClaude（AI）の補足で紹介候補を提示する。
**判定・AIの結果は補助情報です。紹介の可否は担当者が最終判断してください。**

運用は事務所のPC1台（ローカル）を前提とする。外部公開はしない。

## 起動

### 初回
```
cd backend  && npm ci
cd frontend && npm ci && npm run build
```
試作版（v1）の `data/matching.db` が残っている場合は、退避してから起動する（スキーマ非互換）。

### 毎日
`start.ps1` を実行 → http://127.0.0.1:3101
受付フォーム（求職者本人の入力）は http://127.0.0.1:3101/intake

### 環境変数（任意）
| 変数 | 用途 | 未設定時 |
|---|---|---|
| `ANTHROPIC_API_KEY`（または `RIANET_ANTHROPIC_API_KEY`） | AI補足・面談メモ抽出・提案書翻訳・求人票読取・ネット求人検索。Claude Code のクラウド環境では `ANTHROPIC_` で始まる変数が反映されないため `RIANET_ANTHROPIC_API_KEY` を使う | AI機能なしで動作 |
| `CLAUDE_MODEL` | AIモデル（既定 `claude-opus-5-5`） | 既定 |
| `BACKUP_PASSWORD` | バックアップの暗号化キー（**紛失すると復元不可**） | ローカルに平文で保存（外部媒体へは不可） |
| `GOOGLE_MAPS_API_KEY` | 通勤時間の自動計算 | 手入力 |
| `HW_API_ID` / `HW_API_PASSWORD` | ハローワーク求人情報提供 Web API の認証情報 | API取得なし |

## 基本の使い方：条件表から判定
1. 求職者から条件表（Excel・Word・PDF）を受け取る。自社の **条件表テンプレート（Excel）** で受け取ると、AIを使わずに正確に読み取れる（画面からダウンロード）
2. 「条件表から判定」でファイルを選び「読み取る」→ 内容を確認・修正 →「保存して判定する」
3. 登録済みの全求人について **案内可（マッチ度高）／案内可／要確認／案内不可** を判定。要確認は確認すべき事項、案内不可に近い求人は「こう変われば対象」を表示
4. 求人は **「🌐 ネットで求人を探す」**（または条件表の保存時のチェック）で、AIが求職者の条件でハローワークインターネットサービス・求人サイト・事業所の採用ページ等を検索し、求人ページを読んで取り込む。取り込んだ「ネット求人」はそのまま4段階で判定される
   - 検索に使うのは勤務地・職種・賃金などの条件のみ（氏名・連絡先・年齢は送らない）
   - ネット求人は掲載時点の情報。2週間で自動的に無効になる。案内前に必ず掲載元ページで最新の内容を確認する
   - 費用の目安：1回の検索でAI利用料とWeb検索料（1,000回あたり10ドル）がかかる。月額上限は設定画面で管理
5. このほか、CSV・求人票PDFの取込、ハローワーク求人情報提供 Web API（承認後）による毎日の自動取得にも対応

テンプレート以外の様式はAIで読み取る（本人のAI利用同意が必要。氏名・電話・メール等は送信前に伏せる）。

## 業務の流れと画面
| 業務 | 画面 | 主な機能 |
|---|---|---|
| 毎日の確認 | 今日のタスク | 面接・結果入力、入職後フォロー（1週/1か月/3か月/6か月）、在留期限、紹介期限、請求・入金、新着候補、承認待ち、苦情、事業報告（4月） |
| 求職受付 | 求職者／受付フォーム | 本人入力（8言語）→承認、同意日必須、面談記録、面談メモからAIで条件抽出（担当者承認後に反映） |
| 求人 | 求人／事業所 | CSV取込、オンライン提供CSVの定期取込、求人票PDF・画像のAI読取、HW求人の「自社求人化」、労働条件明示項目のチェック |
| 紹介 | マッチング結果 | 足切り＋100点満点、惜しい求人と改善点、AI補足、通勤時間、選考の流れ（履歴付き）、多言語の提案書（印刷・LINE文面） |
| 成約 | 成約・請求 | 手数料計算（届出率・上限警告）、請求・入金、離職と返戻金の自動計算、定着フォロー |
| 法定対応 | 帳簿・報告／苦情受付簿 | 求人・求職・手数料管理簿のCSV、事業報告書の集計、情報公開用の数値、選考ファネル・辞退理由 |
| 管理 | 設定・ログ | 手数料・返戻金規定、AI予算と利用履歴、バックアップ、保存期限による削除予定、操作ログ |

## マッチング判定
1. **足切り**：募集終了・紹介期限切れ／通勤範囲外（都道府県と市区町村をセットで照合。政令市の区に対応）または通勤時間超過／不可の施設種別／必須資格不足（上位資格を考慮）／賃金見込みが希望未満（許容率を超える不足）／夜勤不可・回数超過／勤務可能時間外／週日数超過／年齢（例外事由がある求人のみ）／在留期限切れ／特定技能の受入不可・訪問系（設定で可にした場合を除く）／留学・家族滞在で資格外活動許可なし
2. **加点**（重みは求職者ごとに選択）：職種・施設種別、賃金、勤務地・通勤、雇用形態、休日、経験・資格
3. **注意表示**：在留カード未確認・在留期限90日以内、例外事由のない年齢条件、外国人雇用不可/不明、日本語レベル、許容範囲内の賃金不足など
4. **情報充足率**：情報が少ない求人が高く見えないよう別に表示
5. **賃金比較**：時給・日給は求人の所定時間・日数で月額に換算し、固定手当・夜勤手当×回数を加算。年収見込みは賞与・その他年額も加算

## 法令・運用上の安全装置
- **HW求人のままでは成約登録できない**：求人者から求人申込みを受理し、手数料・返戻金の合意を確認して「自社求人化」してから紹介する
- **転職勧奨の禁止**：自社紹介で無期雇用就職した人に、就職後2年以内に提案書を作る場合は理由の記録が必要
- **個人情報**：AIへは仮名化データのみ送信（氏名・連絡先・住所・生年月日・在留カード番号は送らず、自由記述もマスキング）。求職者ごとのAI同意が必要。本籍・思想信条などの収集禁止情報を入力すると警告
- **保存期限**：求職者の削除は論理削除。紹介終了から保存年数（既定2年）経過後に自動で完全削除
- **監査**：閲覧・登録・更新・AI送信・帳簿出力を操作者付きで記録
- **通信の防御**：127.0.0.1 でのみ待ち受け、Hostヘッダ検査（DNSリバインディング対策）、独自ヘッダ必須（CSRF対策）、URLは http/https のみ保存
- **バックアップ**：毎日3:15に暗号化バックアップ（AES-256-GCM）、世代管理。復元は `node backend/scripts/restore.js <ファイル>`（アプリ停止中）

## 要確認事項（実装はしたが一次資料での確認が必要）
- 管理簿の記載事項・様式・保存期間、事業報告書の定義（6か月以内離職の数え方）、情報公開項目（平均手数料率の算定方法）
- 労働条件明示の項目（2024年改正の変更範囲を含む）
- 求人情報提供サービス（Web API・CSV）の利用規約・仕様書：承認後、設定画面の「ハローワーク求人情報提供 Web API」にURL・データID・XMLタグ名・項目対応を入力（この環境からは仕様書を参照できなかったため、接続は汎用実装で模擬サーバーでのみ検証済み）
- 特定技能（介護）の訪問系業務の可否、外部AI送信の法的整理（委託／外国にある第三者への提供）
- 受付フォームの翻訳（ネイティブ確認を推奨）
